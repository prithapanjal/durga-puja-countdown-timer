## 🪔 Durga Puja Countdown Timer

I built a small desktop countdown app for this upcoming Durga Puja❤️
It shows a live countdown to Durga Puja and changes the greeting throughout the festival — from Mahalaya to Dashami.

## ✨ Features
⏳ **Live Countdown** to Durga Puja 2026
🪔 Festival greetings from Mahalaya to Dashami
🎵 **Mahalaya Audio** with a play button
🌙 **Dark & festive desktop UI**
💻 Lightweight Electron desktop application
⚡ Built with vanilla **HTML, CSS & JavaScript**

## 🛠️ Built With
HTML
CSS
JavaScript
Electron.js

## 🚀 Run Locally
git clone https://github.com/prithapanjal/durga-puja-countdown-timer.git
cd durga-puja-countdown-timer
npm install
npm start
